Questions

Good to know

How is my size chosen?

We compare your chest and waist with the size chart of each top and pick the size whose ranges contain both. If none fit, we show the closest one and say so.

Do I need to upload a photo?

No. The preview is a silhouette scaled to your height and chest, so the fit can be shown without a photo.

Why does the best size change between tops?

Some tops run small and others run large, so the same body can be an M in one and an L in another.

How is the style match decided?

Each style has a rule for each body shape, with a match level and a short tip. Kids get comfort tips that do not depend on body shape.
